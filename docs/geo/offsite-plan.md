# Off-site plan (after launch)

A brand-new name gets recommended when other sites people trust mention it. All of
this is owner work, and none of it may be faked: no fake reviews, no astroturfed posts,
no self-ranked "best" lists.

## Profiles (claim, with the facts.md description, word for word)

- Instagram, TikTok, Facebook page (Malaysian wedding talk lives on these three).
- YouTube: a 60-second "macam mana tetamu upload" video with the brand said aloud and a
  transcript. YouTube is the most-cited domain in Google's AI answers.
- LinkedIn page for FF Dev Studio listing Indahnya.
- Add each profile to the Organization `sameAs` once it exists (agent wires it).

## Earned mentions

- Malaysian wedding portals and blogs that already write "QR gambar majlis" explainers
  (e.g. Portal Kahwin's QR photo-book article, seen 2026-09-19). Offer a free plan and a
  genuine walkthrough; don't pay for a ranking.
- Wedding vendors (pelamin, katering, mak andam, photographers): a free "Lengkap" for their
  next couple in exchange for honest feedback; a vendor page only if they want one.
- Facebook groups for brides-to-be: answer real questions as yourself, disclose you built it.

## Reviews

- After each real event, ask the couple for a review (Google Business Profile once it
  exists, Facebook). Ask everyone, not only happy couples. Never gate reviews.

## Original data (later)

- Once there are events: "berapa gambar tetamu ambil dalam satu majlis" from anonymised
  counts. A real number with methodology is the most citable thing a small brand can own.

## Wikipedia / Wikidata

- Not notable yet. Do not create entries.
